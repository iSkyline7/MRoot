# MRoot
Minimalist tool for getting root access on Galaxy A56 (and other devices)

> **I am not responsible for any damage to your device.**

- - -

# How to use
1. Download apk from releases
2. Install KernelSU (or a supported fork)
>**Galaxy users:** If after running the script your phone fully reboots, you should use [diabl0w's KSU build](https://github.com/diabl0w/KernelSU/releases/) to avoid the kernel panic caused by Samsung KDP
3. Run the exploit

# Methods
>Do **NOT** edit any system/boot partition, it will brick your device.
